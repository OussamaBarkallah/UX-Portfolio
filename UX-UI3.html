Retail Store Mobile UI Concept

Project Overview

A self-initiated concept for a mobile shopping app, designed from scratch to explore a clean, fast, and intuitive e-commerce experience. Inspired by platforms like Amazon but rethought for a mobile-first interaction — with a focus on simplicity, visual clarity, and a seamless path from discovery to checkout.

My Role

Solo project — I handled the entire design process end to end: user flows, information architecture, wireframing, design system, and final UI screens.

The Challenge

Most e-commerce apps overwhelm users with cluttered interfaces, complex navigation, and friction-heavy checkout flows. The question I set out to answer was: how might we create a shopping experience that feels effortless and fast — while keeping the interface clean and visually engaging?

Design Process

To bring this concept to life, I applied a full end-to-end UX/UI process — starting from rough sketches and working through to polished high-fidelity screens. Each stage informed the next, ensuring every design decision was grounded in structure and usability before moving into visual styling.
